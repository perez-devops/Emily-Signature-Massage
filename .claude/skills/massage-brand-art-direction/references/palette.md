# Palette — Boutique Wellness / Holistic Massage

Warm, earthy, low-saturation. Nothing here should read as "clean medical" (cool greys, clinical blue) or
"resort luxury" (black + gold, jewel tones). Every color is desaturated enough to photograph well against
linen, wood, and skin.

## Core Neutrals (≈70% of any composition)

| Name | Hex | Use |
|---|---|---|
| Warm Paper | `#F4EEE4` | Primary background, page/canvas base |
| Sand | `#DCCFB8` | Secondary surface, cards, dividers |
| Putty | `#C7B9A6` | Borders, muted UI elements, disabled states |
| Stone | `#8C8175` | Secondary text, captions, icons |

## Ink (≈20%)

| Name | Hex | Use |
|---|---|---|
| Bark | `#2E2620` | Primary text and line work — used instead of pure black `#000` everywhere |

Pure black and pure white are banned in this system. If a surface needs to go near-white, use Warm Paper;
near-black, use Bark.

## Accents (≈10% combined, used sparingly — never as a large fill)

| Name | Hex | Use |
|---|---|---|
| Sage | `#7A8B70` | Primary accent — CTAs, active states, small icon fills, botanical illustration |
| Terracotta | `#B9764C` | Secondary accent — highlights, seasonal/promo callouts, packaging trim |
| Dried Rose (optional tertiary) | `#C08B7A` | Sparing use only — gift cards, seasonal collateral. Do not pair with Terracotta in the same composition (too close in temperature; picks one or the other) |

## Pairing Rules

- Default composition: Warm Paper background + Bark text + one accent (Sage OR Terracotta), not both, per
  screen/asset.
- Sage reads as "everyday/service" (booking flow, price list, weekly social). Terracotta reads as
  "seasonal/warm/promotional" (gift certificates, holiday specials, packaging trim).
- Never place Sage and Terracotta directly adjacent at equal weight — pick one as dominant accent and use
  the other only as a small secondary touch (e.g., a single line or icon) if both are needed.
- Contrast check: Bark on Warm Paper ≈ 11:1 (passes AA/AAA for body text). Stone on Warm Paper ≈ 3.3:1 —
  fine for captions/secondary text at larger sizes, not for small body copy.
- Gradients: avoid smooth multi-stop gradients (reads as tech/app). If a gradient is unavoidable (e.g. a
  soft vignette in a photo), keep it a single-hue tonal shift within the neutral family, never accent-to-accent.

## What This Palette Is Reacting Against

- Teal + white "medical spa" branding
- Black + gold "luxury resort" branding
- Lavender/purple + soft-pink "generic wellness app" branding
- Neon/bright gradient "startup wellness app" branding

If a generated asset drifts toward any of the above, it's off-brand — pull back to the neutrals and re-check
accent usage.
